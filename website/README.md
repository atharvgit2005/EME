# EME website

Static surrealist product website. Preview from the EME repository with:

```sh
python3 -m http.server 4731 --directory website
```

Open http://127.0.0.1:4731. No credentials, model calls or backend are required.
The interactive design study is an illustration, not the engine or a training vote.
The Studio link requires a local EME server. The typography loads DM Sans and
Instrument Serif from Google Fonts, with system fallbacks.

The Sites-managed checkout lives separately under `../sites/eme-surreal`; changes
must be copied there and packaged with Sites to update the hosted version.
